# 環境知識競賽練習系統 (新版)

本資料夾為可直接發佈至 **GitHub Pages**（或任何靜態網站託管服務）的網頁版本，所有題庫與程式皆採用相對路徑載入（`data/questions_*.js`），無須後端伺服器即可運作。

## 檔案結構

```text
web/
├── index.html                  # 主應用程式（單頁式網頁）
├── README.md                   # 說明文件
└── data/                       # 各組別題庫（依選擇動態載入）
    ├── questions_國小.js
    ├── questions_國中.js
    ├── questions_高中職.js
    └── questions_社會.js
```

## GitHub Pages 發佈步驟

1. 在 GitHub 建立一個新的 Repository（公開或私人皆可）。
2. 將本 `web/` 資料夾內的 **所有檔案與 `data/` 資料夾** 上傳至 Repository 的根目錄（確認 `index.html` 與 `data/` 位於同一層）。
3. 前往 Repository 的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**，Branch 選擇 `main`（`/ (root)`）後點擊 **Save**。
5. 等待數十秒後，即可透過 GitHub Pages 提供的網址使用系統。

## 使用說明

### 1. 三層登入身分
- **一般使用者（選手）**：選擇由管理者建立的帳號，輸入密碼登入，支援個人錯題本、積分累積與點數兌獎。帳號名單儲存在雲端，學生可在任何裝置登入。
- **訪客（免密碼）**：免密碼即可直接體驗測驗與練習功能。
- **管理者**：帳號密碼請洽系統管理者。可管理使用者（新增、編輯、拖曳排序、啟用/停用/刪除、調整積分）、檢視各組題庫並更正答案。
- **帳號名單的線上管理**：所有學生與管理者的帳號、密碼、管理安全碼都存放在 Google 試算表的「帳號密碼管理」分頁，可以直接在試算表中修改（詳細規則見 Apps Script 程式碼開頭的說明），網頁重新整理後即生效。

### 2. 測驗與積分規則
- 支援 **國小組、國中組、高中職組、社會組** 題庫，依年段動態載入 `data/questions_<組別>.js`。
- 提供多題型練習與「驟死淘汰賽」等測驗模式，搭配積分／榮譽點數與點數兌獎中心。
- **專屬錯題本**：集中顯示所有組別的錯題，可透過年段核取方塊自由篩選並進行錯題練習或匯出 PDF（管理者帳號不顯示個人錯題本與積分圖示）。

### 3. 雲端同步（Google 試算表）
- 系統支援透過 Google Apps Script Web App 與 Google 試算表進行雲端資料同步（包含使用者名單、使用紀錄、歷史錯題紀錄、選手積分總覽、兌獎與點數異動紀錄、答案更正等）。
- 雲端網址設定在 `index.html` 內的 `DEFAULT_CLOUD_GAS_URL` 常數，如需連結自己的 Google 試算表，請修改此網址。
- 更新 `Google雲端試算表_AppsScript程式碼.gs` 後，請在 Apps Script「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署。部署後第一次有網頁連線時，系統會自動建立「帳號密碼管理」分頁與預設管理者。
- 刪除學生、清理資料、修改點數、更正答案等管理操作，都需要通過雲端的管理者驗證。
